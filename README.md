# โต๊ะ UNO ออนไลน์

เว็บแอปเกม UNO เล่นสดพร้อมกันได้สูงสุด 8 คนต่อห้อง **ไม่ต้องล็อกอิน ไม่ต้องติดตั้งอะไร** — ส่งลิงก์ให้เพื่อน เพื่อนกดเข้ามาเล่นได้เลย

ต่างจากตัวเกมเวอร์ชันแรก (ที่ทำเป็น Claude Artifact) ตรงที่ตัวนี้มีเซิร์ฟเวอร์ของตัวเอง เลยไม่ติดข้อจำกัดเรื่องต้องมีบัญชี Claude หรือต้องเชิญทีละอีเมล

## วิธี Deploy ขึ้น Railway (แบบเดียวกับที่เคยทำกับบอท LINE)

1. สร้าง repo ใหม่บน GitHub (แยกจาก repo ของบอท LINE นะครับ อย่าเอาไปรวมกัน) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (`server.js`, `package.json`, โฟลเดอร์ `public/`)
2. เข้า [railway.app](https://railway.app) → กด **New Project** → **Deploy from GitHub repo** → เลือก repo ที่เพิ่งสร้าง
3. Railway จะตรวจเจอ `package.json` แล้วรัน `npm install` กับ `npm start` ให้เองอัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม
4. ไปที่แท็บ **Settings** ของ service นี้ → หัวข้อ **Networking** → กด **Generate Domain** จะได้ลิงก์สาธารณะ (เช่น `uno-production.up.railway.app`)
5. เปิดลิงก์นั้นในเบราว์เซอร์ ถ้าเห็นหน้าโลโก้ UNO! แสดงว่าใช้งานได้แล้ว ส่งลิงก์นี้ให้เพื่อนได้เลย ไม่ต้องมีบัญชีอะไรทั้งสิ้น

## วิธีเล่น

1. ใส่ชื่อเล่น กด "สร้างห้อง" จะได้รหัสห้อง 4 ตัว
2. กด "คัดลอกลิงก์ชวนเพื่อน" ส่งให้เพื่อน (ลิงก์จะพาเพื่อนเข้าห้องอัตโนมัติ ไม่ต้องพิมพ์รหัสเอง)
3. รอผู้เล่นครบ 2-8 คน แล้วกด "เริ่มเกม"
4. กติกามาตรฐาน UNO ครบ: การ์ดสี/ตัวเลข, Skip, Reverse, +2, Wild, Wild +4, ปุ่มตะโกน UNO! และปุ่มจับคนลืมพูด UNO

## ข้อจำกัดที่ควรรู้

- ห้องเกมเก็บอยู่ใน**หน่วยความจำของเซิร์ฟเวอร์เท่านั้น** ไม่มีฐานข้อมูลถาวร ถ้า Railway รีสตาร์ท service (เช่น ตอน deploy โค้ดใหม่) ห้องที่เล่นค้างอยู่จะหายไป ต้องสร้างห้องใหม่
- ห้องที่ไม่มีใครออนไลน์เกิน 30 นาทีจะถูกลบทิ้งอัตโนมัติเพื่อไม่ให้หน่วยความจำโป่ง
- ไม่มีระบบล็อกอิน ใครมีลิงก์ก็เข้าห้องได้ (ถ้าไม่อยากให้คนแปลกหน้าเข้าห้อง ก็แค่ไม่เผยแพร่รหัสห้อง/ลิงก์ในที่สาธารณะ)
